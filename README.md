# İkinci El Araç Fiyat Tahmin ve Pazar Analizi 🚗📊

Tech İstanbul "AI Destekli Web Uygulaması Geliştirme Atölyesi" kapsamında geliştirilen web tabanlı karar destek platformu projesi.

## 📌 Proje Hakkında
Otomobil alım-satım süreçlerinde kullanıcıların piyasa verilerini analiz ederek araç fiyatlarını karşılaştırabileceği ve trendleri görebileceği pratik bir web arayüzü sunar.
